## Pure DP Proposal Fixed Modules

1. Cover:
   - School.
   - Programme.
   - Term/year.
   - Target score or package.
   - Product name.
2. Client situation and proposal conclusion.
3. Official course structure and assessment table.
4. Coursework/assessment workload map.
5. Target-score management logic.
6. Why DP is required.
7. DP service contents:
   - brief/rubric拆解.
   - structure and topic framing.
   - research/source planning.
   - draft/feedback/quality-control loop.
   - submission preparation.
8. Team configuration and responsibility split.
9. DP process:
   - course setup.
   - task intake.
   - outline.
   - draft.
   - QC.
   - final check.
10. Course-by-course DP plan.
11. Sources and pending materials.
12. Quote page only if requested.

## Mixed DP + Exam/陪跑 Case Pattern

Use this when the user asks for a DP package together with course understanding, exam preparation, or weekly learning execution.

Confirmed cases:

- `UCL_GHS_大二全年DP安心包与考试陪跑方案_2026-27.pdf`
- `悉尼大学商业管理大一学业规划陪跑DP服务方案_已删考核节点表.pdf`

Fixed modules:

1. Student/program summary.
2. Product split:
   - DP handles coursework writing, reports, presentations, projects, capstone/portfolio tasks.
   - 陪跑/专业课 handles exam, test, core concepts, weekly learning execution, and practice.
3. Course/task assessment summary.
4. DP service value.
5. Exam/陪跑 service value.
6. AI智慧学习系统 use path.
7. Daily/weekly/monthly service actions.
8. Expected effect without grade guarantees.
9. Quote only when requested and separated by product.

Rules:

- Do not use a long raw assessment-node wall in client-facing versions if a concise service-value plan is requested.
- DP scope and exam/陪跑 scope must be separately visible.
- DP quote and陪跑 quote must be calculated separately.
- Do not expose API key, endpoint URL, internal formula, margin, bottom line, or negotiation room.

## Assessment Excel Fixed Fields

For DP all-assignment整理表, use these fields:

- 课程代码.
- 课程名称.
- 评估项目.
- 占比.
- 个人/小组.
- 截止日期.
- 形式/时长.
- 具体要求.
- 提供服务.
- 原价.
- 折后价.
- 来源/备注 when needed.

Rules:
- Every assessment row must be traceable to a course code and course name.
- Translate official English descriptions into Chinese.
- Exams/tests/quizzes are excluded from DP quote unless user explicitly says otherwise; route them to陪跑/专业课 if needed.
- Group projects and writing/presentation/report tasks are usually in DP scope.
- Do not expose internal pricing formulas, API keys, endpoint URLs, bottom line, or margin.
