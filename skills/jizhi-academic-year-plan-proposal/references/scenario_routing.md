# Product Routing Boundary

Read this file only when a request mixes DP and academic planning or the intended product is ambiguous.

| Request | Owner | Quote owner |
|---|---|---|
| 学业规划、全年陪跑、学业管家、专业课/陪跑课、AI智慧学习系统 | `jizhi-academic-year-plan-proposal` | planning quote rules |
| DP安心包、卓越安心包、毕业无忧、纯DP、DP全包 | `dp-proposal-designer` | `dp-product-new-customer-quote` |
| DP Assessment整理、DP价格、DP报价Excel | `dp-product-new-customer-quote` | private quote API |
| DP + 陪跑/考试辅导/学业规划 | annual skill controls combined structure; DP skill supplies only the DP module | calculate and display two independent quote blocks |

Hard boundary:

- DP covers approved coursework/project deliverables and their managed process.
- Planning covers course learning, professional teaching, weekly execution, AI learning tracking and exam preparation.
- Exam/test/quiz coaching is never silently included in DP scope.
- Never blend DP and planning prices into one unexplained calculation.
