# Service Logic

## Core Judgment Formula
Write the core judgment as:

`该学生的主要风险不在于 [surface issue]，而在于 [program context] + [assessment pressure] + [ability gap] + [DDL concurrency]. 因此方案需要同时覆盖 [knowledge support]、[execution management]、[AI智慧学习系统 practice] 和 [stage review].`

Examples of useful risk dimensions:
- English academic writing and referencing.
- Reading density and theory transfer.
- Quantitative/calculation stability.
- Software/tool operation plus oral explanation.
- Portfolio continuity.
- Group work and presentation.
- Timed exam/viva.
- Multi-DDL concurrency.

## Course Classification
Classify every module with:
- `cluster`: subject family.
- `priority`: 重点 or 非重点.
- `risk`: 低 / 中 / 中高 / 高.
- `assessment_focus`: essay, report, portfolio, coursework, quiz, exam, viva, presentation, group work, software output.

重点课程 usually includes any course with:
- timed exam or high-stakes viva,
- software + oral explanation,
- high target score pressure,
- core major gateway content,
- repeatedly weak prerequisite skills.

非重点 does not mean unimportant. It means risk can be controlled through standard planning, AI智慧学习系统, and execution support unless DDL/feedback changes.

## Hour Allocation
Default to the standard package unless the user explicitly requests a custom plan.

Standard package defaults, verified against the latest questionnaire when quoting:
- 重点课程: 6节专业课 + 10节规划执行/陪跑课.
- 非重点课程: 2节专业课 + 8节规划执行/陪跑课.

When building a normal方案:
- Only classify courses as重点 or 非重点.
- Do not create bespoke per-course hours unless the user says定制方案/定制课时 or provides exact hours.

For custom plans:
- For custom plans only, use user-provided hours first.
- If estimating, mark all hours `暂估`.
- Keep ratios explainable.
- Show specialist teaching and planning/execution support separately.

Suggested ratio patterns:
- High-risk exam/viva course: more specialist hours.
- Writing/portfolio-heavy course: more planning/execution and feedback hours.
- Software course: specialist intro + repeated practice/check sessions.
- Low-risk reading/portfolio course: lighter specialist hours + regular AI智慧学习系统/weekly checks.

Never imply that hours guarantee grades.

## Annual Path
Default path:
1. 入学前诊断
2. 课程资料建档
3. 开学资料抓取
4. 每周规划执行
5. 作业交付支持
6. 考试/口试冲刺
7. 反馈与升级

Each path step must include a concrete output:
- 学生画像
- 课程风险雷达
- 暑期任务表
- 课程知识库
- 正式课程档案
- 作业节点表
- 周报
- 错因记录
- 理解确认清单
- 模拟记录
- 阶段复盘

## Weekly Loop
Use this as the default weekly operation:
- 周一：资料同步。学生上传 lecture, reading, assessment brief, rubric, teacher reminders.
- 周二/三：专业课深度讲解。Solve hard concepts and assessment logic.
- 周四：AI智慧学习系统练习与检测。Generate quiz, case variations, oral checks, error records.
- 周五/六：规划执行课复盘。Check whether the student can explain knowledge, assignment direction, and likely questions.
- 周日：周报与下周计划。Output mastery, errors, DDL risk, add-class suggestion, next tasks.

## AI智慧学习系统 Logic
AI智慧学习系统 is not described as an assignment-writing tool. It is a trackable learning space.

Seven-node flow:
- 课程知识库: Handbook, lecture, reading, rubric, assessment brief, feedback.
- 学生画像: foundation, weak points, error causes, prompt dependency, expression ability.
- 学: explain concepts and relationships.
- 练: generate quiz, case questions, variations.
- 用: transfer knowledge to assessment contexts.
- 造: student reverse-teaches AI, designs cases, catches wrong answers.
- 人工介入: repeated errors, lagging progress, complex judgment, urgent DDL.

## Service Delivery Modules
Every plan should make parent-visible value clear:
- Course file completeness.
- Missing material requests.
- Weekly completed/uncompleted tasks.
- DDL risk.
- Monthly parent feedback.
- Feedback-to-next-stage adjustment.

## Six Planning Logic Items
Every plan draft must explicitly cover these six decision items so the proposal is not only a course list:

1. `个人学业画像`: school/program fit, language level, academic habits, weak points, execution style.
2. `问题诊断与定位`: what is most likely to cause lost marks or delayed progress.
3. `目标差距分析`: gap between current baseline and target pass/60+/GPA/high-score goal.
4. `课程优先级`: 重点/非重点 or DP/陪跑 boundary, with reasons.
5. `阶段行动建议`: what to do before term, early term, midterm, DDL/exam period, and review stage.
6. `学业风险清单`: DDL, language, writing, quantitative, exam, group work, software, attendance, and material-missing risks.

## Service Value And Expected Effect
For each plan, include:
- `给客户提供什么`: official course research, course file setup, weekly execution plan, professional teaching, AI智慧学习系统 tracking, DDL/risk reminders, feedback review, parent-visible progress.
- `服务内容是什么`: actions by 学业规划师/规划执行课老师/专业课老师/AI智慧学习系统.
- `预期效果`: clearer course path, earlier DDL start, lower missed-task risk, improved understanding checks, parent can see progress; never phrase this as guaranteed grade/pass.
